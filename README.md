# FP&A Planning & Variance Dashboard

A synthetic planning and management-reporting demo for budget, actuals, rolling forecast, variance drivers, and executive commentary.

## Demonstrates
- budget vs actual vs forecast
- monthly / quarterly variance analysis
- favorable / unfavorable classification
- departmental drilldown
- rolling forecast scenarios
- executive commentary patterns

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
